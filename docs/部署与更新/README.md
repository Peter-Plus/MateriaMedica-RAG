# 部署与更新

现有线上地址：`https://brag.worldlinesite.com`；服务器登录账号：`ubuntu@129.226.116.120`。下面按改动类型选择操作，不需要每次都重新部署整个项目。Windows 命令中的 `xxx\BCRAG` 只是示例，请换成**自己电脑上的项目目录**；服务器上的 `/opt/bcrag` 是现有线上目录，不需要按个人电脑路径修改。

| 改动 | 看哪个文件 | 是否重启后端 |
| --- | --- | --- |
| 本地启动、Key 配置与调试 | [本地运行与调试](本地运行与调试.md) | 修改后端代码或配置后需要 |
| Python API、提示词、检索代码 | [后端更新](后端更新.md) | 是 |
| 向量、检索策略、embedding 模型 | [RAG更新](RAG更新.md) | 视代码或配置变更而定 |
| Electron 界面与客户端打包 | [前端更新](前端更新.md) | 通常不需要 |
| 新增《伤寒论》等古籍或更新文本 | [文献更新与扩展](文献更新与扩展.md) | 只导入文本时不需要 |
| 首次部署、模型 Key、线上状态和费用 | [其他](其他.md) | 视操作而定 |

可分发的古籍文本统一放在项目 `文献/原文/`。服务端 `/opt/bcrag/.env` 存模型 Key，`/opt/bcrag/data/` 存账号、对话和知识库。日常上传代码或文本时不要覆盖后两处。
