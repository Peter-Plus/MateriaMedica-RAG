# 文献更新与扩展

## 增加《伤寒论》等古籍，需要改 RAG 吗？

**通常不用改检索流程。**现有导入器允许多份 UTF-8 `.txt`，每个文件以文件名作为文献标识，查询会在全部已导入文献中检索，回答的来源列表也会显示书名。新书导入后立即能用关键词检索；向量可按[RAG 更新](RAG更新.md)单独补充。

需要注意的是：切分器最擅长当前《本草綱目》的格式。若《伤寒论》文本没有相同的章节标记，系统仍会按长度切段，但“章节/条目”可能只显示默认标题。请先用测试问题检查命中段落、书名和行号，再决定是否整理文本格式或修改切分器。不要把未经核实的章节名当成原文出处。

## 准备文本

1. 确认取得和分发方式合法，记录书名、版本、来源和整理方式；项目当前数据库只保存文件名，不单独保存版本字段，建议把版本写入文件名，例如 `伤寒论-某版本.txt`。
2. 保存为 UTF-8 `.txt`，单文件默认不超过 20 MB。尽量保留章节标题和条文顺序；清理广告、目录噪声及重复页眉，但保留可核对的原始版本。
3. 文件名在知识库中唯一。同名重新导入且内容变化时，会替换**该书**的全部片段和已有向量；其他文献、账号和对话保留。文件名不同则视为另一本资料。

## 上传并导入现有服务器

假设本地文件为项目根目录下的 `文献\原文\伤寒论-某版本.txt`。先在 Windows PowerShell 执行，并将 `xxx\BCRAG` 换成自己电脑上的项目目录：

```powershell
cd "xxx\BCRAG"
scp ".\文献\原文\伤寒论-某版本.txt" ubuntu@129.226.116.120:/home/ubuntu/
ssh ubuntu@129.226.116.120
```

登录服务器后执行：

```bash
sudo install -d -o bcrag -g bcrag /opt/bcrag/文献/原文
sudo install -o bcrag -g bcrag -m 644 /home/ubuntu/伤寒论-某版本.txt /opt/bcrag/文献/原文/伤寒论-某版本.txt
sudo -u bcrag bash -c 'cd /opt/bcrag && python3 -m server.ingest "文献/原文/伤寒论-某版本.txt"'
sudo -u bcrag bash -c 'cd /opt/bcrag && python3 -m server.search "桂枝汤的相关条文"'
```

把命令里的示例文件名换成实际文件名。导入后可在客户端知识库状态看到文献数和片段数；无需重启后端。若标题或来源不准，先修订文本或分段规则，再重新导入同名文件。不要仅凭模型回答判断文献是否正确入库。
