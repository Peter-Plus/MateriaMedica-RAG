# 后端更新

适用于修改 `server/` 下的 Python 代码，包括 API、提示词、检索和导入程序。下面是现有服务器的日常更新命令；新增 Python 依赖或修改数据库表结构时，还需另行处理依赖或数据迁移。

## 1. 在 Windows PowerShell 打包并上传

将首行的 `xxx\BCRAG` 换成自己电脑上实际的项目目录。

```powershell
cd "xxx\BCRAG"
tar -czf "$env:TEMP\bcrag-server-update.tar.gz" --exclude='__pycache__' server
scp "$env:TEMP\bcrag-server-update.tar.gz" ubuntu@129.226.116.120:/home/ubuntu/
ssh ubuntu@129.226.116.120
```

## 2. 登录服务器后覆盖代码、重启、检查

```bash
sudo tar -xzf /home/ubuntu/bcrag-server-update.tar.gz -C /opt/bcrag --no-same-owner
sudo chown -R bcrag:bcrag /opt/bcrag/server
sudo systemctl restart bcrag.service
sudo systemctl is-active bcrag.service
curl -fsS https://brag.worldlinesite.com/api/health
```

预期服务状态为 `active`，健康接口返回 `"ok": true` 和 `"model_configured": true`。若启动失败，查看 `sudo journalctl -u bcrag.service -n 50 --no-pager`。

这套命令只上传 `server/`，不覆盖 `.env`、`data/`、古籍文本或客户端。仅修改后端代码时无需重新导入知识库。若删除或重命名过 Python 模块，需检查服务器上是否有旧文件遗留；若修改数据库结构，不要仅依靠上述复制命令。
