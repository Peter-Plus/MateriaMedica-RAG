# 其他：模型配置、首次部署与线上状态

## 当前模型与费用

用户选择阿里云百炼华北2（北京）。服务器 `.env` 当前使用兼容接口 `https://dashscope.aliyuncs.com/compatible-mode/v1`、聊天模型 `qwen3.7-flash`、向量模型 `text-embedding-v4`（256 维）。项目专用 API Key 只在服务器 `/opt/bcrag/.env`，文件属主为 `bcrag`、权限 `600`；不要写入客户端、聊天、文档或部署包。模型可用性、价格和预算以[阿里云模型详情](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)、[地域说明](https://help.aliyun.com/zh/model-studio/regions)及[预算管理](https://help.aliyun.com/zh/model-studio/budget-management)为准。

公开注册目前设置每账号每日 40 次、全站每日 200 次问答、最多 100 个账号；应持续关注用量。文本导入不产生模型费用，调用 `--embed` 和正常模型问答会产生 API 用量。

## 首次部署参考

线上后端已部署在 `/opt/bcrag`，以 `bcrag` 系统用户运行 `bcrag.service`，只监听 `127.0.0.1:8000`。Nginx 代理 `https://brag.worldlinesite.com`，并已配置 HTTPS。首次部署新服务器时，需要将项目 `server/` 与 `文献/原文/` 放入服务目录，安装 Python 3.10+，创建权限受限的 `.env`，执行 `python3 -m server.ingest "文献/原文/本草綱目-全文.txt"`，再安装并启用仓库中的 `deploy/bcrag.service` 与反向代理配置。公网只开放 80/443，不直接暴露 8000。

Windows 客户端连接 `https://brag.worldlinesite.com`；健康接口是 `https://brag.worldlinesite.com/api/health`。
