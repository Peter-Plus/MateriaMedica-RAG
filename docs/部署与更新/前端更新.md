# 前端更新

适用于修改 `client/` 下的 Electron 界面、交互或默认服务器地址。**每次交付前端更新，都要同时生成并确认 Windows 便携 ZIP**；前端不需要上传到 Ubuntu 服务器，把新 ZIP 发给使用者即可。仓库根目录 `AGENTS.md` 也将此列为 Codex 更新前端时的交付步骤。

在 Windows PowerShell 执行，先将 `xxx\BCRAG` 换成自己电脑上的项目目录。`npm run make` 已配置 Electron Forge 的 ZIP maker，会直接生成 ZIP，**不需要再手动压缩**：

```powershell
cd "xxx\BCRAG\client"
npm run make
$version = (Get-Content .\package.json -Raw | ConvertFrom-Json).version
Get-ChildItem ".\out\$version\make\zip\win32\x64\*.zip"
```

如在新电脑上首次构建，或依赖有变化，先执行 `npm ci`。要发布一个新的版本号，可先执行 `npm version patch --no-git-tag-version`，再执行上述命令。最后一行必须列出新 ZIP；产物位于 `client/out/<版本号>/make/zip/win32/x64/`。解压后运行 `BCRAG.exe`，无需浏览器。

客户端默认连接 `https://brag.worldlinesite.com`，但旧版本保存的“服务器设置”会沿用。更新 ZIP 后若仍连不上，先看登录页当前服务器地址，必要时在设置中改为该 HTTPS 地址。真实模型 Key 只保存在服务器，不放进客户端。后端 API 路由或响应格式变化时，先确认新版客户端与后端兼容。

## 页面与 Markdown 验证

0.1.2 优化了登录、聊天和出处区域的排版，并支持 AI 新回答及历史回答中的 Markdown 标题、列表、加粗、引用、表格和代码块。解析库与过滤库随客户端打包，无需访问外部 CDN。用户问题和古籍摘录保持原文显示；回答中的 HTML 不执行，远程图片不加载，HTTP/HTTPS 链接使用系统浏览器打开。

在 `client` 目录运行 `npm test`，会通过隐藏的 Electron 窗口检查 Markdown、历史消息、危险内容过滤、出处、等待状态、失败重试、侧栏异常和最小窗口布局。测试使用模拟接口，不连接线上服务、不消耗模型额度；截图保存在 `data/ui-check/`，不要提交到版本库。真实登录、模型生成及系统浏览器打开链接需另行人工验证。

如构建卡在 Electron 下载，可将环境变量 `BCRAG_ELECTRON_ZIP_DIR` 设为本机已缓存的 Electron ZIP 所在目录，再运行 `npm run make`。该目录必须包含与安装版本、平台和架构一致的文件，例如 `electron-v44.5.1-win32-x64.zip`；不设置时仍使用默认下载流程。
