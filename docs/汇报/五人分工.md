## 协作规则

1. 每位成员从项目根目录打开 Codex，确认已读取 `AGENTS.md` 和 `.agents/skills/bcrag-work-log/SKILL.md`。
2. 接手任务前看 `README.md` 和相关 `docs/` 文件，避免改动同一模块产生冲突。
3. 完成任务后记录实际修改、验证结果和仍待处理的问题。若任务归属变化，更新上表。
4. 效果评估由负责成员补充测试题、评判标准和结果；报告目前只保留建议，不编造分数。
